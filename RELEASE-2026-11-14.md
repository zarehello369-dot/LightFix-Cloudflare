## Audit fixes

- Revoke other sessions after password changes; reject stale concurrent login credentials.
- Keep registration decisions and account activation atomic.
- Reconcile photo references after ambiguous database failures; retain evidence when outcome is unknown.
- Preserve original report payload/key on uncertain retries and display the server's original pole.
- Preserve assignment instructions/deadlines on invitation acceptance; expose obsolete invitations as expired.
- Count unread chat in workspace totals; show empty chat and deactivate controls when peer is disabled.
- Synchronize mobile choices after reset/value/disabled changes; prevent dismissing pending task dialogs.
- Consolidate duplicate chat style rules and shared database fixture; syntax-check all project JavaScript.
